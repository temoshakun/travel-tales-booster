# Tripix UI — Open-Source Travel & Booking Platform Boilerplate

Tripix UI is a modern, accessible, and customizable front-end architecture and component library designed for travel agencies, tour operators, and booking platforms. Built with **React 18**, **TypeScript**, **Tailwind CSS**, and **Radix UI** primitives.

## ✨ Key Features
- **Accessible UI Primitives:** Powered by Radix UI and shadcn/ui architecture with full keyboard navigation.
- **Data Fetching & State:** Pre-configured `@tanstack/react-query` setup for asynchronous tour catalog filtering and caching.
- **Form Validation:** Type-safe booking and inquiry forms using `react-hook-form` and `zod` schema validation.
- **Custom Design System:** Extended Tailwind configuration featuring custom typography (`Fraunces` & `Inter`), semantic color tokens (`tangerine`, `sun`, `olive`), and smooth keyframe animations.
- **Unit Testing Ready:** Configured with `Vitest` and `@testing-library/react` for reliable component testing.

```bash
